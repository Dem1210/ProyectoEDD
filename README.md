# ProyectoEDD
<h2>Sistema de Transporte Publico</h2>
<p>Es un sistema dedicado a cargar una base de datos csv de estaciones y conexiones del trasporte pubico y se ecarga de manejarlas a travez de una interfaz grafica hecha con Java.</p>
<p>Este programa es capaz de agregar, eliminar conexiones o estaciones, detectar subredes, hubs de tranferencia y buscar la ruta de menor tiempo.</p>
